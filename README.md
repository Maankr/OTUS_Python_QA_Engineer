# Анализ логов веб-сервера ( на примере файла access.log)

Скрипт для разбора access-логов веб-сервера в формате Apache/Nginx и сбора статистики по запросам.

## Формат лога

Скрипт ожидает строки лога в следующем формате:

%h - - %t "%r" %s %b "%{Referer}" "%{User-Agent}" %d

где:

| Плейсхолдер     | Описание                                    |
|------------------|----------------------------------------------|
| `%h`            | IP-адрес удалённого хоста                     |
| `%t`            | Время получения запроса                       |
| `%r`            | HTTP-метод, URL и версия протокола            |
| `%s`            | Код состояния HTTP                            |
| `%b`            | Количество отданных сервером байт             |
| `%{Referer}`    | URL-источник запроса                          |
| `%{User-Agent}` | HTTP-заголовок User-Agent                     |
| `%d`            | Длительность запроса в миллисекундах          |

Пример строки лога:

1.1.1.1 - - [23/Dec/2015:07:27:57 +0100] "POST /administrator/index.php HTTP/1.1" 200 4494 "-" "Mozilla/5.0 (Windows NT 6.1) AppleWebKit/537.1 (KHTML, like Gecko) Chrome/23.0.1271.17 Safari/537.11" 10000

## Структура проекта

.
├── analyzer.py     # точка входа: чтение файлов, запуск разбора, вывод и сохранение результата
├── parser.py       # регулярное выражение и функция разбора одной строки лога
├── statistics.py   # класс LogStatistics — накопление и агрегация статистики
├── utils.py        # определение файла/директория и получение списка лог-файлов
└── output/         # создаётся автоматически, сюда сохраняются json-файлы со статистикой

## Установка

git clone <ссылка на репозиторий>
cd <репозиторий>

Дополнительная установка зависимостей не требуется

## Использование

Скрипт запускается из командной строки и принимает один аргумент — путь до лог-файла или до директории с логами

**Разбор одного файла:**

python analyzer.py access.log

**Разбор всех файлов в директории:**

python analyzer.py /path/to/logs/

Если передан путь к директории, обрабатывается каждый файл внутри неё; для каждого файла статистика собирается и сохраняется отдельно.

## Что собирает скрипт

Для каждого обработанного лог-файла собирается следующая статистика:

- **total_requests** — общее количество выполненных запросов;
- **methods** — количество запросов по HTTP-методам (GET, POST, PUT, DELETE, OPTIONS, HEAD и др., встретившиеся в логе);
- **top_ips** — топ-3 IP-адресов с наибольшим количеством запросов (адрес и число запросов);
- **top_longest_requests** — топ-3 самых долгих запросов: HTTP-метод, URL, IP-адрес, длительность (в мс), дата и время запроса.

Статистика собирается за один проход по файлу — весь файл не загружается в память целиком, обработка построчная, топ-3 самых долгих запросов ведётся через мини-кучу фиксированного размера.

## Формат вывода

Для каждого лог-файла:

1. Результат выводится в терминал в формате JSON.
2. Результат сохраняется в файл `output/<имя_лог_файла>.json`.

Если было обработано несколько файлов из директории — для каждого из них формируется свой отдельный JSON-файл в `output/` и отдельный блок вывода в терминале.
